# Admin Booking Requests - Quick Reference Guide

## 🔍 Search Feature

### How to Use:
1. Find the search box at the top of the booking requests page
2. Type a customer's name or phone number
3. Results filter automatically as you type
4. Click the X button to clear search

### Search Tips:
- **Name Search**: Type any part of the customer's name
- **Phone Search**: Works with or without country code/formatting
- **Combined Filters**: Search works with all other filters simultaneously

---

## 📋 Aadhar Details

### Where to Find:
**In Admin Panel:**
1. Open any booking request
2. Click "Passenger Info" section
3. Aadhar number appears below DOB (if provided)
4. Displayed in **blue text** for easy spotting

**In Agent Messages:**
- Automatically included in WhatsApp notifications
- Shows under each passenger's details
- Format: "Aadhar: XXXXXXXXXXXX"

### Visual Indicators:
- **Blue Text**: Aadhar number
- **Below DOB**: Easy to find
- **Only when provided**: Won't show if customer didn't enter it

---

## 📅 Date Picker

### How to Clear Selected Date:
**Method 1 (Quick):**
- Click the **X icon** next to the date
- Date clears immediately
- Calendar popup stays closed ✅

**Method 2 (Manual):**
- Open calendar
- Click somewhere else to close
- Use "All Dates" dropdown instead

### Troubleshooting:
- **Issue**: Date not clearing?
- **Solution**: Click directly on the X icon (not the date text)

---

## 🎯 Common Tasks

### Find a specific booking:
1. Use search bar (top of page)
2. Enter customer name or phone
3. Apply additional filters if needed

### View passenger Aadhar:
1. Find the booking
2. Mobile: Tap "Passenger Info"
3. Desktop: Click "Passenger Info" tab
4. Aadhar shows below DOB in blue

### Assign ticket with Aadhar:
1. Select agent from dropdown
2. WhatsApp message auto-sends
3. Aadhar included in passenger details
4. Agent receives complete information

### Filter by date:
1. Click "Pick Date" button
2. Select date from calendar
3. Click **X icon** to clear
4. Or use dropdown filters for quick dates

---

## 💡 Pro Tips

### Search Efficiency:
- **Quick Find**: Type first few letters of name
- **Phone Digits**: Last 4 digits often enough
- **Clear Fast**: Use X button instead of backspace

### Aadhar Management:
- Check Aadhar before assigning to agent
- Aadhar shows automatically in notifications
- No manual copy-paste needed

### Date Filtering:
- Use calendar for specific dates
- Use dropdown for today/tomorrow
- Clear with X when done

## 🐛 Troubleshooting

### Search not working?
- ✅ Check spelling
- ✅ Try phone number instead
- ✅ Clear and retype

### Aadhar not showing?
- ✅ Customer may not have provided it
- ✅ Check in edit modal
- ✅ Only shows if entered during booking

### Date picker won't clear?
- ✅ Click the X icon (not date text)
- ✅ Refresh page if stuck
- ✅ Use "All Dates" dropdown alternative

### Agent not receiving Aadhar?
- ✅ Verify customer entered Aadhar
- ✅ Check agent's WhatsApp connection
- ✅ Re-assign ticket if needed

## 📱 Mobile vs Desktop

### Mobile View:
- Search: Full width at top
- Aadhar: In collapsible "Passenger Info"
- Date Picker: Shows abbreviated date

### Desktop View:
- Search: Fixed width (256px)
- Aadhar: In tabbed "Passenger Info"
- Date Picker: Full date display
