## 📏 Spacing & Measurements

### Page Layout
```
┌─15px────────────────────────────────────────────────15px─┐

│     ↓ 24px gap                                            │
│                                                           │

│     ↓ 20px gap                                            │
```

### Box Dimensions

**Info Box (Invoice Number):**
- Width: 80mm
- Height: Auto (fits content)
- Padding: 6px internal
- Border Radius: 3px
- Shadow: 1px offset

**Billing Box:**
- Width: 85mm
- Height: Auto (fits content)
- Padding: 6px internal
- Border Radius: 2-3px
- Header Height: 8px

**Journey Details Box:**
- Width: 85mm
- Height: Auto (matches Billing box)
- Padding: 6px internal
- Border Radius: 2-3px
- Header Height: 8px

**Total Amount Box:**
- Width: 80mm
- Height: 24px
- Padding: 8px internal
- Border Radius: 3px
- Shadow: 1px offset

**QR Payment Box:**
- Width: 70mm
- Height: Auto (fits QR + text)
- Padding: 6px internal
- Border Radius: 2-3px
- QR Size: 150x150px

**Instructions Box:**
- Width: 100mm
- Height: Matches QR box
- Padding: 6px internal
- Border Radius: 2-3px

## 🎨 Shadow Effect Details

### Visual Representation of Shadow
```
Without Shadow:            With Shadow:

┌────────────┐            ┌────────────┐
│            │              ┌────────────┐
│   TEXT     │              │            │
│            │              │   TEXT     │
└────────────┘              │            │
                            └────────────┘
                          (Gray shadow offset)
```

### Implementation
```
Step 1: Draw gray shadow (offset +1px x, +1px y)
Step 2: Draw actual box on top
Result: Subtle depth effect
```
